- Inventory card edits use a per-row UI unlock state: successful saves relock, failed saves remain editable, and all quantity/unit commands share a guard; existing cycle authorization and server validation remain authoritative.
- «Svuota» on an open inventory clears drafts and confirmed counts of that session only via reset_open_inventory_count (admin, all DB guards before writes, refuses with sent orders or stock adjustments; history entries and stock untouched) and unlocks all cards. Completed-cycle resets use the existing authenticated reopen command; only success clears local editors and refreshes session rows, progress and drafts, while rejection preserves all values. Compact-header thresholds use the document marker and CSS sticky inset with hysteresis, never the changing header rectangle.
- Zone abituali prodotto: solo product_habitual_locations, scritte solo da set_product_habitual_locations (admin/operatore, una sola principale tra le abituali, mai scelta in automatico); informazione organizzativa: non crea card né tocca giacenze, conteggi, Lista o ordini.
- Aggiunte al conteggio durante un inventario aperto solo con add_card_to_open_inventory / add_catalog_item_to_open_inventory (admin+operatore); l'operatore crea prodotti dal catalogo solo tramite quest'ultima (flag app.inventory_catalog_add): fuori dall'inventario resta riservato all'amministratore.
- «Inventario completo» solo con start_full_general_inventory (admin, solo all'avvio): tutte le card prodotto+fornitore attivo, «Senza fornitore» se nessuno; nessun conteggio creato.
- Inventario: U.M. sono solo etichette; chi conta sceglie tra product_inventory_units (scritte solo da manage_product_inventory_unit / set_product_stock_unit), stock_unit_id = principale; conteggi con fattore 1, nessuna conversione; giacenza NULL senza conteggio valido; prodotti senza U.M. hanno la card bloccata ma non bloccano la chiusura; allows_decimals non usato.
- Inventario Modello 2: card = prodotto + ubicazione + product_supplier_link_id (NULL = «Senza fornitore»), chiave unica solo da src/lib/inventory-cards.ts; ogni salvataggio invia la card con _card_explicit, mai ricostruita: nessun conteggio sulla card sbagliata.
- Prima impostazione U.M. di magazzino dalla card Inventario: solo set_initial_stock_unit (admin/operatore, FOR UPDATE, solo da NULL, flag app.stock_unit_first_set accettato dal trigger solo da NULL a valore); proposta solo da initial_stock_unit_options, mai salvata senza conferma: l'operatore non può cambiare un'U.M. già impostata.
- Unit chosen in an inventory card's quantity menu is local UI state keyed by the card key (product+location+supplier link), never by product: two supplier cards of the same product count in independent units.
