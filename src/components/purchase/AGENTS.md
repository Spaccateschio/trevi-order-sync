- Mobile receiving shows one compact list + bottom sheet via pure helpers in receive-outcomes.ts (indicator, Richiesto/Preparato, canConfirmReceipt); amber «!» only for DDT «da controllare» rows and needs an explicit choice in the sheet; excess stays an internal outcome never named to the buyer. Order list DDT text comes from read-only getOrdersDdtSummary.
- Open order, receiving and direct purchase are URL steps on the list page (?ordine=…&ricevi=1, ?acquisto=…) so the single header back arrow returns to the list; no in-panel back buttons.
- Rows with different units are prefilled from the DDT only when the DDT unit equals the row stock unit (stock qty + DDT price basis); otherwise they stay «Da confermare». receive_purchase_order needs every row, so no row is ever silently left out.
